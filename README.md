# DRILL INDEX · 音游键型训练库（移动端应用）

多音游键型训练应用。收录 8 款主流音游、23 个键型模块，每款含判定系统说明、
标志性键型、可拖动查看的循环演示视频与训练要点。

底部导航分四个分区：**首页 / 训练 / 图鉴 / 我的**。

---

## 快速开始

应用是纯静态的（无构建步骤），但**需要用 HTTP 方式打开**才能启用离线缓存：

```bash
cd drill-app
python -m http.server 8777
# 然后浏览器访问 http://127.0.0.1:8777
```

直接双击 `index.html` 也能运行（脚本用的是经典 script，不是 ES 模块），
只是没有 Service Worker 离线能力。

## 装到手机上

1. 把 `drill-app/` 整个目录放到一个能访问的服务器上（或局域网内起上面那条命令）
2. 手机浏览器打开该地址
3. 菜单里选「添加到主屏幕 / 安装应用」
4. 之后从桌面图标启动，全屏运行、离线可用

## 常见改动怎么做

### 改配色 / 间距 / 字号

只动 `src/theme.css`。里面是设计令牌，组件样式全部引用它们：

```css
--accent: #9EFF00;      /* 强调色；进入某款音游/分类时由 JS 覆写成其主题色 */
--bg: #111111;          /* 应用底色 */
--tab-h: 56px;          /* 底部导航高度 */
--sp-4: 16px;           /* 间距刻度 */
--r-m: 14px;            /* 圆角刻度 */
```

改完刷新页面即可，所有组件自动跟随。

### 调整「训练」和「图鉴」的分类

编辑 `src/data/topics.js`。这个文件显式维护两组横切分类：

```js
window.DRILL_TOPICS = {
  train: [                                   // 训练目标
    { id: 'scatter', name: '散点', en: 'Scatter', accent: '#9EFF00',
      desc: '卡片上的说明',
      mods: ['phigros-01', 'cytus-01', ...]  // 填模块 id
    },
    ...
  ],
  family: [ ... ]                            // 键型族
};
```

**为什么单独一个文件**：同一个难点散落在各款音游的不同模块里（比如「点划」
在 Phigros、Lanota、Cytus、maimai 里都有对应内容），这种横切关系没法从模块
自己的关键词字段可靠推断，只能显式维护。改这里不用碰任何页面代码。

改完跑一下校验，能查出 id 写错、重复挂载、空分类：

```bash
node tools/check_topics.js
```

### 加 / 删一款音游

编辑 `src/data/games.js`，在数组里增删一项：

```js
{
  "id": "voez",                          // 唯一 id，用于路由 #/g/voez
  "title": "VOEZ",                       // 显示名
  "alias": "雷亚",                        // 副标题
  "fullAlias": "雷亚游戏 / Rayark",        // 详情页完整别名
  "accent": "#60A5FA",                   // 主题色（会贯穿该游所有界面）
  "desc": "卡片上的一句话简介",
  "tags": ["Tap", "Hold", "Slide"],      // 键型标签
  "gdesc": "详情页的完整介绍",
  "gmeta": ["判定 Perfect / Good / Miss", "特色 变轨轨道"],
  "modules": [ ... ]                     // 该游的模块，结构见下
}
```

### 加一个键型模块

```js
{
  "id": "voez-01",                       // 唯一 id，用于路由 #/m/voez-01
  "num": "01",
  "name": "变轨", "en": "Track Shift", "alias": "轨道移动",
  "desc": "卡片上的简介",
  "meta": "难度 中级 · 判定 Perfect / Good",
  "video": "media/videos/voez-01.mp4",
  "dur": 13,                             // 秒，视频未加载完时用于进度换算
  "segs":   [ {"t": 0, "label": "分段一"} ],       // 可省略
  "legend": [ {"kind": "hit", "text": "说明"} ],  // kind: hit | miss
  "keys": "voez 变轨 轨道",               // 检索关键词（含玩家黑话）
  "para": "正文段落",
  "points": ["要点一", "要点二"],
  "warnLabel": "常见错误",
  "warn": "常见错误说明"
}
```

新模块加完，记得回 `src/data/topics.js` 把它挂到对应的训练目标 / 键型族下。
对应的视频放进 `media/videos/`，封面用 `tools/prepare_assets.py` 自动生成。

### 改应用图标

图标是**用代码画出来的**，不依赖设计源文件：

```bash
python tools/make_icon.py
```

在 `tools/make_icon.py` 顶部改这几个常量即可：

```python
NEON    = (158, 255, 0)      # 信号绿
BG_TOP  = (32, 32, 32)       # 底色渐变（上）
BG_BOT  = (10, 10, 10)       # 底色渐变（下）
LINE    = dict(x0=72, x1=440, y0=348, y1=364)   # 判定线位置
NOTES   = [(158, 176), (256, 88), (354, 228)]   # 三个下落音符（中心 x, 顶端 y）
RING    = dict(cx=256, cy=356, r=78, w=9)       # 判定环
```

一次性输出 `icon-512 / icon-192 / apple-touch-icon / maskable-512 / favicon-32`，
并在项目根目录生成 `icon-preview.png`（多尺寸 + 深浅底对照，用于验收）。

## 工具

| 命令 | 作用 |
|---|---|
| `python tools/verify_http.py` | ★ 验收：10 条路由 + 9 条交互链路，逐条冷启动浏览器，结果以**纯文本**输出 |
| `node tools/check_topics.js` | 校验分类数据：id 是否存在、有无重复、有无空分类 |
| `python tools/make_icon.py` | 生成全套应用图标 |
| `python tools/prepare_assets.py` | 拷贝媒体 + 生成封面与图标 |
| `python tools/extract_data.py` | 从桌面版 HTML 原型重新抽取内容数据 |
| `python tools/shots.py` | 按真实视口渲染各界面截图（人工目视用） |
| `python tools/measure.py` | 读取页面内的真实布局数值（排查"看起来溢出"） |

`verify_http.py` 依赖 `web-ui-headless-verify` 技能里的 `report_server.py`，
它负责托管应用、关掉浏览器缓存、把 `sw.js` 换成自注销版本，
并接收页面 POST 回来的检查结果。

**为什么验收读文本而不是看截图**：无头浏览器的截图有缩放与裁切问题
（请求 390 宽时真实排版视口可能是 496，截图却按 390 裁，看起来像"内容溢出"），
而且拼成长图后缩略显示，数字很容易看错。读文本没有这些误差。

**为什么每条用例单独冷启动浏览器**：如果所有用例跑在同一个页面会话里，
状态会从上游用例带过来，期望值就不确定了。比如先访问 `#/me` 再访问
`#/g/arcaea`，导航高亮合理地停在「我的」（详情页保留来源分区的高亮），
但硬写「期望 home」就会误报。冷启动后每条期望都是确定的。

## 数据是从哪来的

`src/data/games.js` 由 `tools/extract_data.py` 从项目根目录的
`drill-index-prototype.html`（桌面版原型）自动抽取。如果原型页有更新，
可以重新跑一次覆盖；但**之后建议直接编辑 `games.js`**，它才是应用的
单一数据源。

`src/data/topics.js` 不受抽取影响，是手工维护的。

## 设计约束（改 UI 时注意）

- **移动优先**：断点 700px 起转双列，1100px 起三列。正文字号不低于 12.5px。
- **触控尺寸**：可点区域不小于 44px（`--tap-min`）。
- **安全区**：顶栏、底部导航与内容区都已用 `env(safe-area-inset-*)`
  让开刘海与手势条；内容区底部预留了 `--tab-h`，不会被导航栏盖住。
- **主题色贯穿**：`--accent` 由路由切换时覆写，不要在组件里写死颜色。
- **自动播放**：视频静音自动播放（移动端策略要求）；用户手动暂停后不再强制播放。

## 已知限制

- 演示视频是超宽比（1048:320 ≈ 3.28:1），竖屏下较窄；点播放器右下角可全屏，
  全屏时会尝试锁定横屏。
- 全屏播放的横屏锁定依赖 `screen.orientation.lock`，浏览器支持不一，
  不支持时会静默降级。
- 收藏与偏好存在 `localStorage`，清浏览器数据会一并清掉。
- 还没打出原生 APK；当前是 PWA，装到桌面后体验接近原生。
